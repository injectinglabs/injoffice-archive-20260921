# Source chart axis labels

The read-only native bar/column, straight-line and XY chart profiles can retain explicit source axis labels. `chartAxisLabelsPreview: true` enables their rendering alongside `literalBarPreview` or `literalConnectedPreview`. All options default off. A labeled chart does not silently become an unlabeled native chart when label rendering is unavailable: the compiler uses its packaged preview or an identified placeholder.

The first source profile, `explicit-axis-labels-v1`, requires a complete local `c:txPr`: horizontal unrotated text, no wrapping or autofit, zero insets, centered paragraph alignment, explicit point size, bold/italic, language, kerning threshold zero, direct RGB fill, and matching explicit Latin/EA/CS typefaces. Theme fonts, inherited paint, rich overrides and omitted effective font declarations refuse. This preserves source ownership and does not grant editing authority.

Category axes require explicit single-level labels, `auto=0`, centered alignment, `lblOffset=0`, and both skips equal to one. Value axes require explicit linear min/max, zero crossing, positive major unit, `sourceLinked=0`, and format `0` or `0.0` through `0.000000`. Tick positions use exact decimal arithmetic on the aligned `min + k*majorUnit` grid, bounded to 256 ticks per axis. Formatting uses the declared fixed-decimal half-away-from-zero policy; it is not a general SpreadsheetML formatter. Original source value lexemes remain unchanged. Low/high label positions follow the perpendicular axis's value order, including reversal. Only none/out major ticks and no minor ticks qualify. Out ticks require the actual axis at a plot boundary; interior-zero outside ticks are not guessed.

## Supplied fonts and layout

`NativePptxTextLayout.glyphExtents` is optional for existing rendering and required for axis labels. The callback receives `{faceId, contentDigest, glyphId}` and returns that same identity, `unitsPerEm`, and either null for no ink or `{xMin,yMin,xMax,yMax}` in the outline provider's font-up design grid. The digest must identify the exact font resource used by the supplied shaper. Do not return bounds in pixels or silently use a system font. Coordinates and units are bounded integers. A normalized outline grid is supported: both coordinates and units must use that same scale.

The paint-worker adapter reuses its existing digest-verified HarfBuzz outline providers, including quadratic/cubic control points in a conservative hull. These are conservative control-hull bounds, not exact Bézier extrema. The compiler accounts for glyph offsets, bearings, line advances and line height, scaling outward to integer EMU. The initial text mode supports Latin/Common/Inherited characters without controls, explicit LTR Latin shaping and the source language. Other script itemization remains unsupported. Source family/style/size/color are retained; source axis runs do not inherit unrelated host run overrides.

`supplied-outline-margins-v1` reserves measured label extents, one-point minimum clearance, three-point out ticks, source stroke envelopes, and measured perpendicular endpoint clearance. It then fits data into the remaining plot rectangle. It never shrinks fonts, skips source labels or permits overlapping labels. Missing exact fonts, unsupported scripts, insufficient space or overlapping labels cause an identified fallback. This is a disclosed host layout policy, not PowerPoint plot-layout equivalence. Data strokes are clipped to the plot, labels/ticks to the chart frame; all remain within bounded render coordinates and resource budgets.

The playground's supplied-font slide preview offers an explicit source-chart checkbox. Its request is `charts=source-literal`; the server never accepts a user-specified font path. The worker echoes `source_chart_preview: true` and `chart_axis_layout_policy: "supplied-outline-margins-v1"`, which the server and browser bind to the request. Existing requests have neither response field. The separate font-free chart gallery directs labeled charts to this supplied-font preview.

## Qualification and remaining scope

Tests cover strict/transitional source parsing, source ownership and native-contract round trips, malformed styles/formats/tick grids, exact fixed-decimal arithmetic, reverse-aware placements, endpoint corner clearance, conservative real glyph bounds, default-off behavior, missing-font/space/script fallback, request/response identity and actual operator-font vector paint. Generated source fixtures additionally exercise actual Go/WASM extraction and Chrome SVG replay. No render golden or source fixture is rewritten to establish chart parity.

Embedded-workbook references, source chart caches, automatic scales, number-format extensions, other scripts, source-inherited styles, titles, legends, data labels, stacking and further chart families remain separate required work. This axis slice does not close the full native-chart assignment.
