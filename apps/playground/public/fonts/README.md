# Site fonts

These unmodified font files are served from the same origin as the playground.
Loading the site does not request a Google Fonts stylesheet or font download.

Source: [google/fonts at e44c4b0](https://github.com/google/fonts/tree/e44c4b011a820c2cbe2fd2cfa8052037d7edb571).
`manifest.json` records the exact upstream URL and SHA-256 of each file.

Each family is distributed under SIL Open Font License 1.1 with its original
copyright statement and license in the corresponding `OFL.txt`:

- Sora: `sora/OFL.txt`
- Instrument Sans: `instrumentsans/OFL.txt`
- IBM Plex Mono: `ibmplexmono/OFL.txt`

Keep these licenses and the manifest alongside the fonts in hosted builds.
These fonts style the website UI; document rendering uses its own font policy.
