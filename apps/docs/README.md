# InjOffice documentation

Guide content, copy-paste usage, and live package examples. Typecheck with:

```bash
npm run typecheck -w apps/docs
```

The playground mounts this app at `#/guides` on http://127.0.0.1:3100. Native extract/apply samples that talk to `/v1/xlsx` still need the optional Go sidecar on `127.0.0.1:18765`.
